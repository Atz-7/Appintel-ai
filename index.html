What the research is designed to uncover

Integration readiness is more than “does an API exist?”

Authentication

OAuth, API keys, personal access tokens, service accounts, signed requests and credential setup complexity.

Access model

Self-serve versus sales-led access, account prerequisites, admin approval, paid tiers and developer registration.

API surface

REST, GraphQL, webhooks, SDKs, coverage breadth, read/write scope and rate or product limits.

MCP ecosystem

Official hosted/local servers versus third-party or community implementations, plus protocol and tool-scope limits.

Research and verification workflow

A human-supervised research pipeline with checkpointing, structured output and a separate evidence audit.

01 · Seed list

100 apps, grouped into ten categories. Validate names, category balance and duplicates.

02 · Discover

Search vendor docs and relevant sources for auth, access, APIs, MCP and blockers.

03 · Structure

Gemini structured output into a Pydantic schema; preserve evidence URLs and confidence notes.

04 · Checkpoint

Save per-app results, resume completed work, record failures and export JSON/CSV.

05 · Normalize

Reconcile research batches to the original list; normalize QuickBooks Online → QuickBooks and exclude out-of-scope TikTok.

06 · Verify

Cross-check a targeted sample against official docs; record contradictions, limitations and unresolved claims.

07 · Human review

Keep 92 records flagged. Do not turn source confidence into an accuracy claim.

08 · Publish

Expose the directory, evidence links, blockers, audit notes and machine-readable dataset.

Execution transparency: the automated Tavily + Gemini pipeline produced 8 completed app reports in the recorded run; additional records were assembled in separate research batches. Composio connectivity was tested, but the connection exposed meta-tools only—no app-specific toolkit actions were run. The complete 100-app set is therefore not represented as 100 autonomous agent executions.

What this dataset does—and does not—prove

What it supports

  • All 100 target apps have a normalized record.
  • Every record has at least one evidence URL in the source dataset.
  • API/auth/access/MCP/buildability fields are present.
  • Eight records have targeted official-doc audit notes.
  • Known ambiguity and blockers are preserved.

What it does not claim

  • 100% factual accuracy or 100% verified sources.
  • 100 successful API or MCP connections.
  • Every listed MCP is official unless explicitly evidenced.
  • All features are available on free plans.
  • The 74 High classifications are a live integration pass rate.
